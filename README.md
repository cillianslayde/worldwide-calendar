# Worldwide Calendar — Version 3

A rebuilt front-end foundation for a genuinely worldwide calendar.

**Live:** https://cillianslayde.github.io/worldwide-calendar/

## V3 includes
- National, regional and government holidays
- Canadian and U.S. observances including Labour/Labor Day, MLK Day, Presidents' Day, Memorial Day, Juneteenth, Veterans Day, Canada Day, Remembrance Day and Truth and Reconciliation
- International observances
- Cultural and awareness dates
- Christian movable dates
- Wiccan/Pagan Sabbats
- Full-moon Esbat marker
- Moon phases
- Country/region filtering
- Category filtering
- Search
- Hover/focus/click date inspection
- Multiple events on a single date
- Adjacent-month calendar cells

## Important production note
The front end is designed around an extensible event engine. The embedded data is a representative V3 dataset, not a claim to contain every observance in every jurisdiction. A production release should populate the same event structure from comprehensive, appropriately licensed holiday, religious, cultural, regional and astronomical datasets.

## Running it
Open `index.html` in any modern browser (Chrome, Edge, Firefox, Safari). No
build step, no account, no external dependencies — everything is
self-contained in the two local files below.
